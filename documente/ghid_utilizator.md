# Ghid Utilizator - Rapoarte-Solaris

## Introducere

Bun venit la Rapoarte-Solaris! Acest ghid vă va ajuta să utilizați platforma pentru accesare rapoarte, analize și date despre piața energiei solare din România.

## Accesare Rapoarte

### Căutare Rapoarte

1. Navigați la secțiunea **Rapoarte**
2. Utilizați filtrele:
   - **Tip**: Lunar/Trimestrial/Anual/Special
   - **An**: Selectați anul
   - **Cuvânt-cheie**: Căutare text
3. Click pe raport pentru deschidere

### Descărcare Raport

```
1. Deschideți raportul
2. Click buton "Descarcă"
3. Selectați format:
   - PDF (recomandat)
   - Word (.docx)
   - Excel (.xlsx)
   - HTML (pentru web)
4. Salvați pe calculator
```

## Explorare Date Companii

### Căutare Companie

1. Navigați la **Date > Companii**
2. Introduceți:
   - Nume companie
   - Tip (Operator/Producător/etc)
   - Regiune
3. Click **Căutare**
